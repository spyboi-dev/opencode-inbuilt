# OpenCode

OpenCode for iOS. The OpenCode CLI, running on your phone.

Tapping a thread opens the t3code UI, served by the t3 server the engine starts in the guest and wired to the OpenCode 2.3.0 server on this device. The terminal stays under Engine → Show terminal.

## Build

```sh
./build-local-kernarium.sh
```

Produces `build-local/OpenCode-iOS.ipa`.
